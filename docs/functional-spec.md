# 공연 알림 서비스 - 기능정의서 (FRS)

## 문서 정보

- **문서명**: 기능정의서 (Functional Requirements Specification)
- **프로젝트**: 공연 알림 서비스
- **버전**: 1.0

---

## 기능정의서 개요

본 문서는 공연 알림 서비스의 모든 기능을 체계적으로 정의한 문서입니다. 각 기능은 고유 ID를 부여받으며, 화면 단위와 메뉴 계층 구조에 따라 분류됩니다.

### 기능 ID 체계

- **F-XXX**: 대분류 (화면 그룹)
- **F-XXX-YY**: 중분류 (주요 기능)
- **F-XXX-YY-ZZ**: 소분류 (세부 기능)

### 화면 ID 체계

- **1000번대**: 홈 및 공연 탐색
- **2000번대**: 마이페이지 및 계정 관리
- **3000번대**: 팔로우/알림 관리
- **4000번대**: 캘린더
- **5000번대**: 공연 상세
- **6000번대**: 아티스트 상세
- **7000번대**: 셋리스트

## 상세 기능 명세

### F-001: 홈 화면

#### F-001-01: 국내공연 목록

- **목적**: 국내 아티스트의 대중음악 공연 정보 제공
- **데이터 소스**: KOPIS API (`genre='CCCD'`, `festival='N'`, 제외 키워드 '내한')
- **표시 항목**: 포스터, 공연명, 날짜, 장소
- **UI**: 가로 스크롤 (Horizontal Scroll) 또는 그리드

##### F-001-01-01: 필터 (지역/날짜)

- **지역**: 서울, 경기, 인천, 부산 등 전국 주요 리전
- **날짜**: 조회 기간 설정 (기본: 오늘 ~ 1개월)

#### F-001-02: 내한공연 목록

- **목적**: 해외 아티스트의 내한 공연 정보 제공
- **데이터 소스**: KOPIS API (`genre='CCCD'`, 포함 키워드 '내한')
- **표시 항목**: 포스터, 공연명, 날짜, 장소
- **UI**: 가로 스크롤 (Horizontal Scroll) 또는 그리드

##### F-001-02-01: 필터 (지역/날짜)

- **지역**: 서울, 경기, 인천, 부산 등 전국 주요 리전
- **날짜**: 조회 기간 설정 (기본: 오늘 ~ 1개월)

#### F-001-03: 페스티벌 목록

- **목적**: 진행 중이거나 예정된 페스티벌 정보 제공
- **데이터 소스**: KOPIS API (`festival='Y'`)
- **표시 항목**: 포스터, 페스티벌명, 날짜, 장소
- **UI**: 가로 스크롤 (Horizontal Scroll) 또는 그리드

##### F-001-03-01: 필터 (지역/날짜)

- **지역**: 지역별 필터링
- **날짜**: 조회 기간 설정 (기본: 오늘 ~ 1개월)
- **정렬**: 날짜순 (오름차순)

#### F-001-04: 검색창

- **검색 대상**: 공연명
- **검색 방식**: 부분 일치 (LIKE 검색)
- **결과 표시**: 검색 결과 페이지로 이동

##### F-001-04-01: 자동완성

- **트리거**: 2글자 이상 입력 시
- **응답 시간**: 300ms 이내
- **최대 표시**: 10개
- **하이라이팅**: 검색어 부분 강조

### F-002: 마이페이지/로그인

#### F-002-01: 로그인 정보

- **지원 방식**: 구글 OAuth, 카카오 OAuth
- **표시 정보**: 프로필 사진, 이름, 이메일
- **수정 가능 항목**: 프로필 사진, 닉네임

#### F-002-02: Spotify 연동

- **인증 방식**: OAuth 2.0
- **요청 스코프**:
  - `user-read-private`: 사용자 기본 정보
  - `playlist-read-private`: 플레이리스트 읽기
  - `streaming`: 웹 플레이어 재생
- **연동 해제**: 토큰 삭제 및 연동 정보 제거

##### F-002-02-01: 플레이리스트 동기화

- **동작**: Spotify 연동 후 자동 실행
- **프로세스**:
  1. 사용자 플레이리스트 목록 조회
  2. 각 플레이리스트의 트랙 정보 추출
  3. 트랙의 아티스트 정보 수집
  4. 중복 제거 후 추천 아티스트 목록 생성
- **추천 표시**: 최대 20명, 팔로우 빠른 추가 버튼 제공

##### F-002-02-02: 팔로우 아티스트 동기화

- **기능**: 사용자가 스포티파이에서 팔로우한 아티스트 목록을 직접 조회하여 동기화
- **페이지**: `/mypage/spotify-sync`
- **UI**:
  - 팔로우 아티스트 목록 (이미지, 이름)
  - 선택/해제 체크박스 (전체 선택 포함)
  - 기존 팔로우 여부 및 공연 정보 존재 여부(매칭) 표시
  - [선택한 아티스트 팔로우하기] 버튼
- **동작**:
  1. 스포티파이 API로 팔로우 목록 조회 (무한 스크롤/페이지네이션 지원)
  2. 사용자가 동기화할 아티스트 선택
  3. DB에 아티스트 정보 Upsert 및 User-Artist 관계 생성

#### F-002-03: 알림 설정

- **알림 채널**: 푸시 알림 (FCM), 이메일 (선택 사항)
- **설정 항목**:
  - 티켓팅 시작 알림
  - 공연 등록 알림
  - 전체 알림 on/off

##### F-002-03-01: 티켓팅 시작 알림

- **트리거**: 팔로우한 아티스트의 공연 티켓 오픈 시
- **알림 시점**: 티켓 오픈 당일 09:00
- **알림 내용**: "{아티스트명} 공연 티켓이 오픈되었습니다!"
- **딥링크**: 공연 상세 페이지

##### F-002-03-02: 공연 등록 알림

- **트리거**: 팔로우한 아티스트의 신규 공연 등록 시
- **알림 시점**: 공연 등록 후 1시간 이내
- **알림 내용**: "{아티스트명}의 새로운 공연이 등록되었습니다!"
- **딥링크**: 공연 상세 페이지

#### F-002-04: 로그아웃

- **동작**: JWT 토큰 삭제, 로그인 페이지로 리다이렉트
- **세션 정리**: 클라이언트 로컬 스토리지 및 서버 세션 정리

#### F-002-05: 약관

- **제공 문서**:
  - 이용약관
  - 개인정보처리방침
- **표시 방식**: 모달 또는 별도 페이지

#### F-002-06: 고객센터

- **FAQ**: 자주 묻는 질문 5-10개
- **1:1 문의**: 이메일 폼 또는 외부 채널 (카카오톡, 이메일) 연결

### F-003: 알림 설정한 아티스트/공연

#### F-003-01: 아티스트 목록

- **표시 정보**: 아티스트 이미지, 이름, 팔로우 날짜
- **정렬**: 최근 팔로우순 (기본), 이름순
- **기능**:
  - 팔로우한 아티스트 목록 조회
  - 아티스트 추가 [검색 / 스포티파이 가져오기]
  - 팔로우 해제 (삭제)

##### F-003-01-01: 아티스트 추가 (검색)

- **경로**: 아티스트 목록 > [+ 추가] > [검색]
- **기능**: 아티스트 이름 검색 및 결과에서 팔로우
- **데이터**: 앱 내 DB 아티스트 검색

##### F-003-01-02: 아티스트 추가 (스포티파이)

- **경로**: 아티스트 목록 > [+ 추가] > [스포티파이 가져오기]
- **동작**: `/mypage/spotify-sync` 페이지로 이동 (F-002-02-02 참조)

##### F-003-01-03: 팔로우 해제

- **동작**: 목록에서 [삭제] 또는 [언팔로우] 버튼 클릭
- **확인**: 삭제 확인 모달 표시

#### F-003-02: 공연 목록

- **표시 대상**: 알림 설정한 특정 공연
- **표시 정보**: 공연 포스터, 이름, 날짜, 장소
- **필터**: 예정 공연 / 지난 공연

### F-005: 공연 상세

#### F-005-01: 공연 정보

- **표시 항목**:
  - 포스터 이미지 (고해상도)
  - 공연명
  - 아티스트명 (클릭 시 아티스트 상세 페이지 이동)
  - 공연 날짜 및 시간
  - 공연 장소 (지도 링크 포함)
  - 티켓 가격
  - 티켓팅 오픈 일정
  - 공연 설명

#### F-005-02: 예매처 링크

- **제공 링크**: 인터파크, 멜론티켓, 예스24, 티켓링크 등
- **링크 동작**: 새 탭에서 외부 사이트 열기

## 비기능 요구사항

### 성능

- **초기 로딩 시간**: 1초 이내 (FCP)
- **API 응답 시간**: 500ms 이내
- **캐싱 전략**: 검색 등 반복 요청에 대해 In-Memory LRU Cache 적용
- **검색 자동완성**: 300ms 이내
- **이미지 로딩**: Progressive JPEG, WebP 포맷 사용

### 보안

- **인증**: JWT 기반 인증, HttpOnly 쿠키 사용
- **HTTPS**: 모든 통신 암호화
- **XSS 방지**: 사용자 입력 sanitization
- **CSRF 방지**: CSRF 토큰 사용

### 접근성

- **WCAG 2.1 AA 준수**
- **키보드 네비게이션** 지원
- **스크린 리더** 호환
- **색상 대비**: 최소 4.5:1

### SEO

- **메타 태그**: 모든 페이지 title, description 설정
- **OG 태그**: 공연/아티스트 상세 페이지 Open Graph 설정
- **구조화 데이터**: Schema.org Event, MusicGroup 마크업
- **Sitemap**: XML 사이트맵 생성
