# 커밋 컨벤션 (Commit Convention)

## 기본 원칙

- **각 작업 단위마다 커밋**을 수행합니다.
- **Gitmoji 형식**을 사용합니다: `이모지 타입 : 설명`

## 커밋 타입 목록

| 이모지 | 타입         | 설명                           | 예시                             |
| :----- | :----------- | :----------------------------- | :------------------------------- |
| ✨     | **Feat**     | 새로운 기능 추가               | `✨ Feat : 검색 기능 추가`       |
| 🐛     | **Fix**      | 버그 수정                      | `🐛 Fix : 로그인 오류 수정`      |
| 👷     | **Build**    | 빌드 관련 수정                 | `👷 Build : Docker 설정 변경`    |
| 📦️    | **Chore**    | 패키지 매니저, 설정 파일 수정  | `📦️ Chore : 패키지 설치`        |
| 📝     | **Docs**     | 문서(주석) 수정                | `📝 Docs : README 업데이트`      |
| 🎨     | **Style**    | 코드 스타일, 포맷팅 수정       | `🎨 Style : 세미콜론 추가`       |
| ♻️     | **Refactor** | 코드 리팩터링 (기능 변경 없음) | `♻️ Refactor : 변수명 변경`      |
| 🔖     | **Release**  | 버전 릴리즈                    | `🔖 Release : v1.0.0`            |
| 🧪     | **Test**     | 테스트 코드 관련               | `🧪 Test : 로그인 테스트 추가`   |
| 💄     | **Design**   | CSS/UI 디자인 수정             | `💄 Design : 버튼 색상 변경`     |
| 🚑️    | **Hotfix**   | 치명적인 버그 긴급 수정        | `🚑️ Hotfix : DB 연결 오류 해결` |
| 🔨     | **Modify**   | 단순 코드 수정 (오타 등)       | `🔨 Modify : 오타 수정`          |
| 🚚     | **Rename**   | 파일/폴더 이동 및 이름 변경    | `🚚 Rename : 폴더 구조 변경`     |
| ➖     | **Remove**   | 파일 삭제                      | `➖ Remove : 더미 파일 삭제`     |

## 커밋 메시지 작성 팁

1.  **제목은 50자 이내**로 간결하게 작성합니다.
2.  **동사는 현재형**으로 작성합니다 (예: "추가했다" ❌ -> "추가" ⭕).
3.  본문이 필요한 경우 제목과 본문 사이에 빈 줄을 추가합니다.

**예시:**

```text
✨ Feat : 공연 검색 자동완성 기능 추가

- Debounce 300ms 적용
- 최대 10개 결과 표시
- 검색어 하이라이팅 구현
```
